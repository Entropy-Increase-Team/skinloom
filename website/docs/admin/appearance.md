# 外观与主题

在"后台 → 外观"里调整，保存后对所有访客立即生效。

## 主题

自带两套：

| 主题 | 特点 |
|---|---|
| 云织（`default`） | 蓝色系，登录页是居中卡片 |
| 织锦（`brocade`） | 朱红与金色，登录页分栏，皮肤库更紧凑，首页带最新材质与站点数据 |

点"启用"切换。没有自定义首页时，首页也随主题更换。

## 颜色

在主题之上调整亮色、暗色两组常用颜色和圆角，可以用取色器或填任何 CSS 颜色（`#336699`、`oklch(0.6 0.2 300)`）。留空用主题的值；换主题后不合适就点"全部清除"。

## 首页

首页由区块从上到下拼成，可以添加、排序、删除，并修改每个区块的内容：

| 区块 | 可以改 |
|---|---|
| 大标题 | 标题、副标题、背景图、两个按钮 |
| 公告 | 显示站点公告，没有公告时隐藏 |
| 功能介绍 | — |
| 站点数据 | 标题；显示用户、角色、公开材质数 |
| 最新材质、热门材质 | 标题、数量、类型 |
| 文字 | Markdown 内容 |
| 图片 | 地址、说明、链接 |
| 按钮组 | 最多 6 个按钮 |
| 启动器配置引导 | — |

文字可以按语言分别填写。链接只能是本站路径（`/skinlib`）或 `http(s)://` 地址。点"改用主题自带的首页"恢复默认。

## 站点标识与页脚

Logo、浏览器图标、页脚文字（Markdown）和搜索关键词也在这一页，对应设置见[站点设置](./settings.md#站点)。

## 自定义 CSS

加载在主题样式之后，最多 64 KB，**只有超级管理员**能改。可用的类名有首页大标题 `.sl-hero`、登录页侧面板 `.sl-auth-panel`、Markdown 内容 `.sl-markdown`；颜色优先用上面的"颜色"或 CSS 变量（如 `var(--primary)`），换主题时不容易出问题。

## 自定义 JavaScript

用来加统计代码等，最多 64 KB，**只有超级管理员**能改。注意：

- 页面开启了内容安全策略（CSP），外部脚本要用 `document.createElement('script')` 加载；统计服务给的 `<script src="…">` 标签要照此改写。`document.write`、`eval` 不能用。
- 站内切换页面不会重新加载，脚本只在打开网站时运行一次。
- 写坏了导致网站打不开，在服务器上清空：

  ```bash
  skinloom settings set theme.custom_js null
  ```

## 自己做主题

主题是一个 `plugin.json`（`kind: "theme"`）加样式表和图片，内置主题在源码的 `themes/` 目录下，可以照着写。规范见[插件与主题](../plugins/overview.md)。目前只能使用内置主题，安装第三方主题要等插件平台开放。
