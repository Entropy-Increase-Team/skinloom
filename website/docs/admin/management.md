# 后台管理

管理员点页头的角色徽章进入后台。

## 管理员的权限

| 角色 | 能做什么 |
|---|---|
| 管理员 | 管理**普通用户**和他们的角色、处理举报、发通知、改站点设置、看审计日志 |
| 超级管理员 | 以上全部，并且能管理其它管理员、修改角色、改自定义 CSS / JavaScript |

- 谁都不能修改自己的角色或状态。
- 站点至少保留一个正常状态的超级管理员。
- 脚本用 `skinloom admin token` 输出的令牌调用管理接口，它有超级管理员的权限，注意保管。

## 概览

用户、角色、材质、存储和待处理举报的总数，以及最近 31 天每天的注册数和上传数。"发送通知"也在这里：可以发给所有用户、只发给普通用户，或按 ID、邮箱发给一个人，正文是 Markdown。

## 用户

按邮箱、昵称或 ID 搜索，按角色、状态筛选。可以改昵称、邮箱、积分、邮箱验证状态、密码，封禁或删除：

- 封禁或设置新密码后，对方在所有设备上立即退出登录。
- 换了邮箱后，新邮箱默认未验证，可以同时勾选"邮箱已验证"。
- **后台删除是立即、永久的**，没有用户自己注销时的 30 天宽限期。超级管理员要先降级才能删除。

## 角色

按角色名、UUID 或 ID 搜索。可以改名、转给其他用户、更换皮肤与披风（必须在主人的衣柜里）、删除。权限和用户管理相同。

## 举报

默认显示待处理的举报。每条可以：

- **删除材质**：举报者拿回举报费并获得奖励；同一材质的其它举报一起结案；
- **封禁上传者**：同用户管理里的封禁；
- **驳回**：举报费不退，提交时给过的奖励收回。

一条举报只能处理一次。

## 审计日志

记录登录、注册、账号变更、后台的每一项操作和设置修改：时间、操作者、对象、地址、改了什么。筛选框里输入动作名精确筛选，以 `.` 结尾表示前缀，例如 `admin.` 只看后台操作。审计日志不随用户删除而删除。

## 翻译

改写界面上的任何文字：按键名（如 `nav.skinlib`）或原文（如"皮肤库"）搜索，在对应语言下填新的说法，保存后立即生效。

原文里花括号中的占位符（如 `{site}`）必须原样保留。目前只能改网页界面的文字，邮件和接口的提示语不在其中。

命令行写法：

```bash
skinloom settings set i18n.overrides '{"zh-CN":{"nav.skinlib":"皮肤广场"}}'
skinloom settings set i18n.overrides null    # 全部恢复
```

## 系统状态

一页看清服务器的情况：数据库能否连接、迁移是否完成、后台任务有没有积压或失败、邮件和站点地址是否设置，以及版本、数据库类型、存储用量。排查问题时先看这里。

多副本部署时，显示的版本和启动时间属于处理这次请求的那个实例。
