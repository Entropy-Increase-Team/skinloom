# 翻译与系统状态

## 改写界面文字

后台的 **翻译** 页（`/admin/translations`）可以改写网页界面上的任何文字，相当于 Blessing Skin 的 `language_lines`：

1. 按键名（如 `nav.skinlib`）或文字（如"皮肤库"）搜索；
2. 在对应语言下填入新的说法，留空就用原文；
3. 保存，所有页面立即生效。

原文里花括号中的占位符（例如 `登录 {site}` 里的 `{site}`）由页面填入实际内容，改写时必须原样保留，否则不能保存。勾选"只看已改写的"可以检查改过哪些文字。

改写保存在设置 `i18n.overrides` 里，也可以用命令行：

```bash
skinloom settings set i18n.overrides '{"zh-CN":{"nav.skinlib":"皮肤广场"},"en":{"nav.skinlib":"Gallery"}}'
skinloom settings set i18n.overrides null   # 全部恢复原文
```

目前只能改写网页界面的文字。邮件、兼容 BS 的接口提示和启动器登录的错误信息由服务端生成，暂时不能在这里改写。

## 系统状态

后台的 **系统状态** 页（`/admin/status`）显示这台服务器的情况：

| 部分 | 内容 |
|---|---|
| 检查结果 | 数据库能否连接、迁移是否执行完、后台任务是否积压或失败、邮件与站点地址是否设置 |
| 服务端 | 版本、构建时间、Go 版本与系统、运行方式（`server.role`、`web.mode`）、启动时间 |
| 数据库 | 类型与版本、迁移版本、响应时间（不显示连接串和用户名） |
| 材质存储 | 本地目录或 S3、文件数与占用空间 |
| 后台任务 | 等待中、超时、已失败（保留 7 天）的任务数 |
| 邮件、配置 | 发送方式；配置版本、当前主题、改过的设置数 |

多实例部署时，页面显示的是处理这次请求的那个实例的版本与启动时间；数据库、任务和存储是共享的。

脚本可以用管理员令牌读取同样的数据：

```bash
curl -H "Authorization: Bearer $(skinloom admin token)" http://127.0.0.1:17546/api/v1/admin/status
```
