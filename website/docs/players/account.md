# 账号

## 注册与登录

- **注册**：页头的"注册"，填邮箱、昵称和密码（8–128 个字符）。站点关闭了注册时没有这个按钮。
- **登录**：用邮箱和密码。连续输错几次后需要先完成验证码，输错太多次要等一会儿再试。
- **第三方登录**：站点开启了 GitHub、Microsoft 等登录时，登录页会有对应的按钮，见下文[第三方登录](#第三方登录)。

## 验证邮箱

注册后会收到一封验证邮件，点开链接，再点"确认验证邮箱"。链接 24 小时内有效。

没收到？登录后页面顶部有"重新发送"。有的站点要求先验证邮箱，才能创建角色、上传材质或在启动器里登录。

## 忘记密码

登录页的"忘记密码？"→ 填邮箱 → 打开邮件里的链接设置新密码（链接 30 分钟内有效）。设置新密码后，所有设备上的登录都会退出。

## 个人资料

点页头的昵称进入"个人资料"：

| 想做的事 | 在哪里 |
|---|---|
| 改昵称、界面语言 | 基本资料。语言也决定站点发给你的邮件用什么语言 |
| 改密码 | 修改密码。改完后其它设备、启动器、授权过的应用都需要重新登录 |
| 改邮箱 | 修改邮箱。新邮箱需要重新验证，旧邮箱会收到通知 |
| 看在哪些设备上登录过 | 登录设备。可以退出某一台，或"退出其它所有设备" |
| 启动器登录了几个 | 游戏启动器。可以一键让它们全部重新登录 |
| 头像 | 在衣柜里给一个皮肤点"设为头像"，显示它的头部 |

怀疑账号被盗：先改密码，再到"登录设备"里退出其它所有设备。

## 第三方登录

用 GitHub、Microsoft 等账号第一次登录时：

- 如果它的邮箱和本站某个已验证邮箱的账号相同，会直接登录那个账号；
- 否则可以选择**创建新账号**，或**登录已有账号并绑定**。

个人资料页的"已绑定的账号"可以绑定或解除。通过第三方登录创建的账号一开始没有密码，不能用邮箱密码登录，也不能在启动器里登录；在个人资料页设置一个密码就都可以了。

## 授权的应用与令牌

用户中心的"应用与令牌"：

- **授权过的应用**：别的网站或程序（论坛、服务器面板等）用本站账号登录时，会请你授权。这里可以随时撤销。
- **个人访问令牌**：给自己的脚本调用接口用，创建时选择权限和有效期，令牌只显示一次。
- **我的应用**：自己开发应用时在这里注册，见[开放平台与接口](../development/api.md)。

## 积分与签到

上传材质、收藏、创建角色可能消耗积分（具体多少由站点决定，页面会提前显示）。用户中心可以**签到**领取积分，每天或每隔一段时间一次。

## 通知

页头的铃铛显示未读通知，点开一条即标为已读。

## 注销账号

个人资料页最下方，输入当前密码即可注销：

- **30 天内**用原来的邮箱和密码登录，账号就会恢复；
- **30 天后**账号和私有材质被永久删除，公开材质保留，上传者显示为"已注销用户"。

管理员需要先被降为普通用户才能注销。
