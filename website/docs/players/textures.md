# 皮肤与披风

站点上的皮肤和披风统称**材质**。公开的材质都在**皮肤库**里，你收藏的和自己上传的材质在你的**衣柜**里。角色只能穿衣柜里的材质。

## 上传

皮肤库 →"上传"，选择 PNG 图片、填名称，选择公开或私有：

| 类型 | 图片尺寸 |
|---|---|
| 经典皮肤（Steve） | 正方形（64×64、128×128……），或宽是高的两倍（旧版 64×32） |
| 纤细皮肤（Alex，手臂 3 像素宽） | 正方形 |
| 披风 | 宽是高的两倍（64×32……） |

- 上传页会根据图片自动选类型，可以手动改。
- **私有材质**只有你自己（和管理员）看得到，通常比公开材质消耗更多积分。上传前页面会显示要花多少积分。
- 皮肤库里已经有一模一样的公开图片，或者你以前传过同一张，会直接跳到那个材质，不重复上传、不扣积分。
- 文件大小和宽度的上限由站点设置，超出时页面会提示。

## 皮肤库

可以按类型（皮肤、经典、纤细、披风）筛选、按名称搜索，按"最新"或"最受欢迎"排序。每个材质有自己的页面，可以 3D 预览、收藏、举报。

## 收藏与衣柜

- 在材质页点"收藏"，材质进入你的衣柜（可能消耗积分）。
- 在衣柜里可以给材质起一个只有自己看得到的名字，或者把它移出衣柜。移出后，穿着它的角色会自动脱下；站点开启了退还时，当初花的积分会退回来。
- 可以给衣柜里的皮肤点"设为头像"。

## 管理自己上传的材质

在材质页的"管理材质"里：

- **重命名**；
- **改类型**：要符合图片尺寸。皮肤改成披风（或反过来）时，穿着它的角色会脱下；
- **设为私有 / 公开**：设为私有要补上差价，设为公开会退回差价，页面会提前显示数额。设为私有后，它会从别人的衣柜里移除，他们的积分会退还；
- **删除**：不可撤销。收藏过它的人会拿回积分，穿着它的角色什么也不穿。

## 举报

觉得某个材质有问题（盗用别人的作品、内容违规等），在材质页点"举报"写下理由。站点可能会收取举报费（举报成立后退还）或给予奖励。处理结果在用户中心的"我的举报"里查看。

## 图片地址

想在论坛签名或其它网页里引用：

| 地址 | 内容 |
|---|---|
| `/avatar/player/<角色名>` | 角色的头像，加 `?size=64` 调整大小，加 `&3d` 得到立体的头 |
| `/avatar/user/<用户 ID>` | 用户的头像 |
| `/preview/<材质编号>` | 皮肤正面和背面的预览图，`?height=200` 调整高度 |
| `/raw/<材质编号>` | 下载原图（站点可以关闭下载） |
