# 鸣谢

## Blessing Skin

**[Blessing Skin Server](https://github.com/bs-community/blessing-skin-server)** 是 SkinLoom 的设计参考与致敬对象。Blessing Skin 多年来定义了自托管皮肤站的形态——衣柜、角色、皮肤库、积分、插件生态——也培育了一个活跃的社区。SkinLoom 在重新实现时保持了与它外部协议的兼容，并提供迁移工具，希望让 Blessing Skin 的站长与玩家能够平滑过渡。

部分翻译文本与渲染算法思路源自 Blessing Skin（MIT 协议，Copyright (c) 2016-present The Blessing Skin Team），版权声明保留在仓库的 `NOTICE` 文件中。
