## 基础组件：用 CLI 装，再按规矩改

基础组件用 `shadcn add` 一次装了 44 个，底层是 Base UI。shadcn 的组件代码就放在仓库里，可以随便改。不过我们只改尺寸、圆角、颜色、阴影和动效，代码风格保持上游的样子，以后能用 `shadcn add --diff` 对照上游的更新：

- 按钮和输入框从 32px 高改为 36px，触屏上 40px；圆角从 10px 改为 8px；
- 按下时缩到 0.98，不再往下挪 1 像素；过渡写明属性，不用 `transition-all`；
- 浮层的阴影换成主题 token，遮罩换成新 token `overlay`；
- 徽章不再是胶囊形，加了"成功""警告"两种；
- 分段控件选中时用主色淡底，原来的灰底在白卡片上几乎看不出来。

改的时候踩了几个坑，都在组件总览页上一眼看出来了：

- **滑块没有轨道。** 组件里写的是 `data-horizontal:h-1`，Tailwind 把它理解成 `[data-horizontal]` 属性，而 Base UI 实际设的是 `data-orientation="horizontal"`。这个对应关系在 `shadcn/tailwind.css` 里，`shadcn init` 会帮你引进来，手写样式表时就漏了。我们照 `shadcn eject` 的做法，把用到的几段抄进了 `globals.css`。
- **链接被读成按钮。** 用 `<Button render={<Link />}>` 渲染链接，Base UI 会加 `role="button"`。现在链接一律用新加的 `ButtonLink`。
- **CSP 拦了一段脚本。** Base UI 会在页面里放一小段内联脚本，没有 nonce 就被我们的内容安全策略挡掉了。用 Base UI 自带的 `CSPProvider` 把 nonce 交给它就好了。
- **CLI 装错了地方。** 依赖装进了应用而不是 `packages/ui`，还装了一个名叫 `cn` 的无关 npm 包，导入路径也写成了应用的别名。都已手工改正。

## 皮肤站自己的组件

皮肤在列表里一律用**双面视图**：后端 `/preview` 画的正反面，同一行里人物一样高。需要"活"的地方用**单面视图**，也就是 3D。

最复杂的是首页展示区 `SkinCarousel`：

- 三个角色放在同一个 3D 画布里：当前的在走路，前一个、后一个缩小、半透明地站在两边。只开一个 WebGL 上下文，比开三个预览省得多；
- 每 6 秒换下一个，头像下面的进度条同步走；悬停或键盘焦点在里面时暂停，手动切换后停止自动播放；
- 系统设置了"减少动效"时，不走路也不自动轮播；
- 滚出屏幕时停止渲染。

调的时候发现，把三个人一起转 30° 会让左边那个转到中间那个身后去，最后只让当前的那个转身。另外，小一号的角色是绕身体中心缩放的，脚会悬空，要往下挪 16 ×（1 − 0.62）个单位才能和中间的站在同一个地面上。

其它组件：确认对话框 `useConfirm()`（代替浏览器自带的确认框，最严重的操作要先输入邮箱）、复制字段、拖放上传、未保存提示条、用量条、状态点、相对时间、材质选择器……共享组件自己要显示的字（"复制""取消"）由网站按访客的语言统一提供，插件拿到的是同一套。
