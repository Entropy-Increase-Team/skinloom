## 本期完成

**可用性**
- 关闭服务时，打开着的页面（SSE）让关闭等满 15 秒，浏览器预连接的空闲套接字再拖 5 秒 → 关闭时结束所有事件流、关闭未使用的连接，现在毫秒级完成。
- 前端崩溃后若子进程占着输出管道，监管者永久卡住、前端不再重启 → `WaitDelay` + 按行写日志的 Writer，3 秒内识别。
- 前端端口被占用时网关会把公网流量转给别的程序 → 启动前检查端口，被占用则换空闲端口。
- Windows 上 `skinloom` 被强制结束时 Node 残留 → 作业对象；Linux 用 `Pdeathsig`。
- Docker `server` 镜像的 `/data` 对非 root 用户不可写；镜像构建缺 `.npmrc`。

**正确性**
- 设置在并发重载时可能回退到旧快照 → 只接受不旧于当前版本的快照（CAS）。
- `server.trusted_proxies`、`server.public_url` 写在模板里却没实现 → 实现前者（新包 `realip`），删除后者（用 `site.url`）。
- 配置拼写错误被悄悄忽略 → 告警；端口、日志格式、代理 CIDR 增加校验。
- MySQL `TIMESTAMP` 的 2038 问题 → `DATETIME(6)`。
- 缺令牌返回 422 → 401。
- Windows 打包可能产出 CRLF 的 `start.sh` → `.gitattributes`。

**安全**
- 转发头只信可信代理，客户端 IP 取最右侧非可信地址；路径规范化后再路由；默认安全响应头；不列目录；区块链接与图片 URL 过滤；Node 运行时校验官方 SHA-256；令牌文件原子创建；SSE 连接数上限。

**性能**
- 组件日志器缓存处理器：每条日志 8 次分配 → 0 次（约 1050 → 700 ns）。

## 测试

| 范围 | 新增 |
|---|---|
| Go | 端到端（真实端口、SSE、热更新、带长连接快速关闭）、启动器（测试程序自身充当假前端，含孙进程占管道）、网关 / 代理头 / 路径、`realip`、主题资源、设置快照、密钥并发、配置校验、发布订阅、日志 |
| 前端 | vitest：URL 过滤、主题样式注入过滤、请求超时与错误处理、刷新抖动 |
| CI | `go test -race`（Linux）、staticcheck、govulncheck、前端单测、依赖审计 |

关键回归测试都先确认"不修复时失败"：去掉 `WaitDelay` 时启动器测试卡 30 秒失败；去掉关闭时的事件流处理时端到端测试超时失败。

结果：Go 12 个包全部通过（易受时序影响的包连续跑 3 遍），前端 30 个测试通过；staticcheck、govulncheck、Web 生产依赖审计均无问题。
