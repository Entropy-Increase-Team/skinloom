# 0007 插件存储不开放 SQL

- 状态：已接受（2026-10-23）
- 相关：设计文档 05 §4.3

## 决策
插件只能使用三种与数据库方言无关的存储：KV、带索引槽位的文档集合（`plugin_docs`，清单声明索引字段 → 映射到 `s1..s3 / n1..n3 / t1` 列并建复合索引）、插件私有文件空间。

## 理由
三种方言的迁移脚本对插件作者是沉重负担；裸 SQL 也会让沙箱、配额与性能保证失效（BS 的插件靠 `Schema::hasTable` 自行建表，是事故来源之一）。

## 影响
复杂查询需要拆集合或建反向索引；若将来确有需求，以方言中立的 schema DSL 形式开放，并另立 ADR。
