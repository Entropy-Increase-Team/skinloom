# 0016 个人资料、设备管理、注销与后台用户管理

- 状态：已接受（2026-10-24）
- 相关：ADR 0012、0015；设计文档 02 §1（F13、F14、F31、F45）、03（S04、S08）、04 §13（M1 验收）

## 背景
M1 收尾。Blessing Skin 的问题：`?lang=` 未经校验就写进 `users.locale`，之后该用户每个请求都报 500（S04）；改密码、改邮箱只登出当前会话，其它设备与"记住我"仍然有效，账号被盗后无法踢人（S08）；注销立即硬删除，误操作无法挽回；普通管理员与超级管理员的边界只在部分接口上检查。

## 决策
- **个人资料**（`/user/profile`，接口在 `/api/v1/me` 下，均需会话 + CSRF 头）：
  - 昵称与语言偏好。语言只接受站点提供的语言或空（跟随浏览器），其它值返回 422，永远不会写进数据库（S04）。偏好同时决定邮件语言，保存后写入本浏览器的语言 Cookie。
  - 改密码、改邮箱都要验证当前密码；同一账号的密码确认 15 分钟内最多错 5 次（429），会话被盗也无法借此慢慢猜密码。
  - 改密码、改邮箱后，**除当前设备外的所有会话立即失效**（S08）。
  - 改邮箱：只改大小写时保留验证状态与会话；换成新地址时清除验证状态，向旧地址发送变更通知、向新地址发送验证链接（同一事务入队）。
  - `/.well-known/change-password` 跳转到个人资料页，密码管理器可以直接带用户去改密码。
- **设备管理**：列出账号的有效会话（地址、浏览器、最近活跃，当前设备排在最前），可以单独退出某个设备或"退出其它所有设备"。会话 ID 是令牌的 SHA-256，展示给本人不构成凭据。
- **注销账号**：需要当前密码；软删除（`status = deleted`、`deleted_at`），立即吊销全部会话。30 天宽限期内用原密码登录即恢复（审计 `account.restored`）；过期后后台每小时清理一次，会话与令牌随外键级联删除，审计记录保留，邮箱可以重新注册。管理员不能注销自己的账号（需先被降级，与 BS 一致），站点不会意外失去管理员。
- **后台用户管理**（`/admin/users`、`/api/v1/admin/users`）：
  - 列表按 ID 倒序、游标分页（每页最多 100）；按邮箱、昵称（不区分大小写）或 ID 搜索，按角色、状态筛选。
  - 权限规则集中在一处（`mayManage`）：管理员只能管理普通用户；超级管理员管理所有人；只有超级管理员能改角色；任何人都不能改自己的角色或状态，也不能在后台删除自己；超级管理员必须先降级才能删除。最后一个有效的超级管理员不能被降级或封禁（409）：移除超级管理员的事务先写同一行 `system_state`（`lock.superadmins`）再计数，在 PostgreSQL / MySQL 的 READ COMMITTED 下也会排队执行，两人同时互相降级不会都成功。`admin.token` 视为超级管理员，但同样受"最后一个超级管理员"保护。
  - 封禁或重设密码会让该用户在所有设备上退出。管理员换了用户的邮箱时，新地址视为未验证，除非同一请求明确设置 `emailVerified`。任何状态修改都会取消待生效的注销，管理员因此可以替用户恢复账号。
  - 后台删除为立即硬删除，写审计 `admin.user_deleted`（保留邮箱与昵称）。
- **审计日志**（`/admin/audit`、`GET /api/v1/admin/audit`）：管理员可见，按动作（以 `.` 结尾表示前缀，如 `account.`）或操作者筛选，游标分页。后台修改记录改了哪些字段，以及角色、状态、积分、邮箱的前后值。

## 备选方案
- 注销立即硬删除：实现最简单，但误操作或账号被盗后注销都无法挽回。
- 宽限期内由管理员审核恢复：多一道人工流程，小站没人处理；用原密码登录即恢复对用户最自然。
- 角色权限做成可配置的权限表：M1 只有三种角色，固定规则更容易审查；细粒度权限留到插件平台（v2）再议。
- 改密码后连当前设备也退出：更"安全"，但用户刚输入过密码，再登录一次只增加摩擦。

## 影响
- 不新增数据表：`users.deleted_at`、`sessions` 与 `audit_logs` 在 M1 第一部分已经建好。
- 暂缓：头像（需要材质，M2）、暗色模式偏好入库（目前存在浏览器）、积分流水表（随 M2 积分系统交付；在此之前积分修改的前后值记在审计日志里）、BS 的 search-string 搜索语法。
- M1 验收（03 的 S01–S08、S15）：S07（皮肤库排序字段）随 M2 皮肤库一起验收，其余均已有测试覆盖。
